# Winhance_Cloud
Enhance your Windows experience by effortlessly debloating, optimizing and customizing your system, giving you more control over how Windows performs

ITALIAN

## Winhance Cloud Versione All-in-One:

Winhance – Windows Enhancement Utility – è un'applicazione C# progettata per alleggerire (debloat), ottimizzare e personalizzare l'esperienza d'uso di Windows. Dalla gestione del software alle ottimizzazioni di sistema e alla personalizzazione, Winhance offre tutto il necessario per migliorare i sistemi Windows 10 e 11.

NOTA: Winhance è un progetto open-source indipendente e non è affiliato, approvato o associato in alcun modo a Microsoft. "Windows" è un marchio registrato di Microsoft Corporation. Eventuali somiglianze con le Impostazioni di Windows o altre interfacce Microsoft sono il risultato naturale della creazione di uno strumento di ottimizzazione per Windows utilizzando i framework dell'interfaccia utente nativi del sistema operativo.

## Funzionalità attuali
### Software e App
- Sezione App e funzionalità di Windows
	* Interfaccia con funzione di ricerca e legenda esplicativa
	* Sezioni organizzate per App di Windows, Funzionalità legacy e Funzionalità facoltative
	* Rimozione e installazione con un clic degli elementi selezionati
	* Gestione di script e attività pianificate tramite il menu di supporto delle App di Windows
- Sezione App esterne
	* Installazione di varie applicazioni utili tramite WinGet (integrazione API COM di WinGet basata su https://github.com/marticliment/WinGet-API-from-CSharp)
	* Le categorie includono browser, utility multimediali, visualizzatori di documenti e altro ancora

### Ottimizzazione
- Interfaccia con funzione di ricerca e navigazione rapida
- Interruttori (toggle) e controlli di selezione per ogni impostazione
- Impostazione del livello di notifica UAC
- Impostazioni della privacy
- Ottimizzazioni per gaming e prestazioni
- Aggiornamenti di Windows
- Impostazioni di risparmio energetico con selezione del piano energetico
- Impostazioni audio
- Preferenze di notifica

### Personalizzazione
- Interfaccia con funzione di ricerca e navigazione rapida
- Interruttori (toggle) e controlli di selezione per ogni impostazione
- Selettore del tema di Windows (modalità scura/chiara)
- Personalizzazione della barra delle applicazioni
- Personalizzazione del menu Start
- Personalizzazione di Esplora file

### Strumenti avanzati
- Creazione di ISO di Windows personalizzate con WIMUtil (Windows Installation Media Utility), inclusa l'aggiunta di driver dal sistema operativo corrente
- Creazione di file autounattend.xml basati sulle selezioni effettuate in Winhance

### Altre impostazioni
- Gestione delle impostazioni di Winhance (e di Windows) tramite file di configurazione Winhance:
Salvataggio delle impostazioni attualmente applicate in Winhance in un file di configurazione per una facile importazione su un nuovo sistema o dopo una nuova installazione di Windows.
- Cambio del tema di Winhance (modalità chiara/scura)

Per maggiori dettagli, controlla la home page: https://winhance.net/

## Winhance Cloud Version All-in-One:

Winhance - Windows Enhancement Utility - is a C# application designed to debloat, optimize and customize your Windows experience. From software management to system optimizations and customization, Winhance provides everything you need to enhance Windows 10 and 11 systems.

NOTE: Winhance is an independent, open-source project and is not affiliated with, endorsed by, or associated with Microsoft in any way. "Windows" is a registered trademark of Microsoft Corporation. Any similarities to Windows Settings or other Microsoft interfaces are a natural result of building a Windows enhancement tool using native Windows UI frameworks.

## Current Features
### Software & Apps
- Windows Apps & Features Section
	* Searchable interface with explanatory legend
	* Organized sections for Windows Apps, Legacy Capabilities, and Optional Features
	* One-click removal and installation of selected items
	* Control scripts and scheduled tasks via Windows Apps Help menu
- External Apps Section
	* Install various useful applications via WinGet (WinGet COM API integration based on https://github.com/marticliment/WinGet-API-from-CSharp)
	* Categories include Browsers, Multimedia utilities, Document viewers, and more

### Optimize
- Searchable interface with quick nav control
- Toggle switches and selection controls for each setting
- Set UAC Notification Level
- Privacy Settings
- Gaming and Performance Optimizations
- Windows Updates
- Power Settings with Power Plan selection
- Sound Settings
- Notification Preferences

### Customize
- Searchable interface with quick nav control
- Toggle switches and selection controls for each setting
- Windows Theme selector (Dark/Light Mode)
- Taskbar Customization
- Start Menu Customization
- Explorer Customizations

### Advanced Tools
- Create Custom Windows ISO's with WIMUtil (Windows Installation Media Utility) including adding drivers from current OS
- Create autounattend.xml files based on your Winhance selections

### Other Settings
- Manage Your Winhance (and Windows) Settings with Wihance Configuration Files:
Save settings currently applied in Winhance to a config file for easy importing on a new system or after a fresh Windows install.
- Toggle Winhance's theme (Light/Dark Mode)

For more details, check Homepage: https://winhance.net/
